# 洋芋粑帝国

贵州花江镇背景的横版 2D 像素喜剧回合制游戏。小航前世垄断全球洋芋粑生意，在集团五十周年庆上中毒身亡；再睁眼，青梅竹马小惠正站在他的摊前。

用 Godot 4 打开 `project.godot`，按 F5 从集市序章开始。也可以打开 `school.tscn`，按 F6 直接试玩第一场校园战斗。

- E 或回车推进对话，Esc 跳过集市序章
- A / D 或 ← / → 移动，E 与小惠交谈或继续剧情
- 在镇上向排在最前面的客人接单，每份做好交给客人后再接下一单。按 E / 空格洗、削、蒸、捣碎、揉饼、翻面与交单。按 1 / 2 选择配料，按 1 / 2 / 3 选择酱料，也可以点击对应按钮。留意煎制时间条的绿色区间。
- 战斗中按 1 出招、2 吃洋芋粑、3 强化反击，也可以点击按钮
- 回家后按 1 或 2 决定怎样使用唯一一块洋芋粑。校门口事件后到教室与小惠交谈，随后剧情会根据昨晚的决定显示升学选项。R 重开当前场景。
- 按 M 静音或恢复背景音乐（不影响音效）

校园战中，洋芋粑保护小航渡过吃下它的回合，并强化接下来的三次出招。强化反击可以同时击退围上来的对手。

集市第一视角开场、横版集市和校门口像素图均为本项目生成。集市环境声由离线合成的交谈和叫卖声混录。

背景音乐按场景切换：集市《赶场调》、做饭《翻面歌》、校门口、校门混战、深夜卧室与教室各一段，全部是八位风格的五声音阶循环曲。曲子由 `tools/make_music.py` 纯代码合成，没有用外部素材（`python tools/make_music.py` 可重新生成，需要 ffmpeg 编码 ogg）。循环点在渲染时就把尾音按整曲长度回卷，所以接缝处不会断。切换场景时 `music.gd` 会用两个播放器交叉淡入淡出。
