# 洋芋粑帝国

一款发生在贵州花江镇的横版 2D 像素喜剧回合制游戏。主角前世垄断全球洋芋粑生意，在集团五十周年庆上中毒身亡。再次睁眼，他在镇上的洋芋粑摊前看见青梅竹马小惠，并觉醒了洋芋粑系统。

用 Godot 4 打开 `project.godot`，按 F5 运行。

- E 或回车推进对话，Esc 跳过序章
- A / D 或 ← / → 移动，E 与小惠交谈或开始挑战
- 战斗中按 1 / 2 / 3 或点击按钮，选择出招、吃洋芋粑或唱山歌
- R 重开

留意裁判下一回合的动作。洋芋粑能挡下重击，小惠接上山歌可以打断蓄力。她在一场对战中只能接唱一次。

第一视角开场和横版集市背景为本项目生成。集市环境声由离线合成的街坊对话和叫卖声混录。
